# Academic Lab Records

A consolidated home for undergraduate coursework and laboratory records across electrical and electronics engineering, programming, and machine learning.

## Browse by subject

The complete subject-wise catalogue is maintained in **[ACADEMIC-LAB-RECORDS.md](ACADEMIC-LAB-RECORDS.md)**.

| Subject | Included work |
|---|---|
| Electronic Circuits | Rectifiers, Zener regulator, multivibrators and oscillators |
| Machine Learning | Regression, classification, clustering, SVM, CNN, GAN and data preprocessing |
| Python Programming | Six modules covering fundamentals through object-oriented programming |
| Instrumentation Systems and Measurements | Power, energy, bridge, temperature, displacement, phase and frequency measurements |
| Circuits and Networks | Mesh analysis, nodal analysis, Thevenin, Norton and maximum power transfer |

## How this archive is organised

- The catalogue groups work by academic subject rather than by the original repository names.
- Original repositories are linked directly and remain unchanged, preserving their files and commit history.
- Notebooks, datasets, diagrams and other original assets remain available in their source repositories.

## Adding future work

Use a consistent experiment record: aim, theory, circuit or block diagram, apparatus, procedure, raw observations, calculations, results, discussion and references.

This is an academic archive. Inclusion in the index does not imply independent verification or production-level validation.
