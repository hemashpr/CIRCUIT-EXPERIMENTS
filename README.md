# Academic Lab Records

Consolidated undergraduate academic work in Electrical and Electronics Engineering, programming, instrumentation, and machine learning.

This repository contains the subject-wise copies of the experiment records and supporting files. The source repositories are preserved separately as provenance and backup.

## Subject folders

| Folder | Subject | Contents |
|---|---|---|
| [01_Electronic_Circuits](01_Electronic_Circuits/) | Electronic Circuits | Nine experiment records: rectifiers, Zener regulator, multivibrator and oscillators |
| [02_Machine_Learning](02_Machine_Learning/) | Machine Learning | Algorithm records, Python implementations, notebooks, datasets, case studies, figures and reports |
| [03_Python](03_Python/) | Python Programming | 30 Markdown exercises across Modules 1–6 |
| [04_Instrumentation_Systems](04_Instrumentation_Systems/) | Instrumentation Systems and Measurements | EXP1–EXP8 and additional measurement records |
| [05_Circuits_and_Networks](05_Circuits_and_Networks/) | Circuits and Networks | Mesh and nodal analysis, Thevenin, Norton and maximum power transfer |

## Catalogue

See **[ACADEMIC-LAB-RECORDS.md](ACADEMIC-LAB-RECORDS.md)** for the subject-wise experiment catalogue and source-repository references.

## Organisation principles

- Subject-first structure, with descriptive experiment and project folder names.
- Original file contents are retained; filenames are cleaned only where necessary to make the archive navigable.
- Source repositories remain unchanged.
- Data files, notebooks, scripts, figures and reports are kept alongside their relevant experiment wherever available.

## Scope and limitations

This is an archive of coursework and experiment records, not a claim that every experiment has been independently validated. Some source repositories contain only a README or written procedure; the archive preserves what was present rather than inventing missing circuit diagrams, observations, or results.
