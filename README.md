## Repository conventions

Each experiment should ideally contain:
1. Objective and circuit under test
2. Theory and governing equations
3. Circuit diagram and component values
4. Procedure and instrument settings
5. Raw observations and calculations
6. Results, uncertainty or error discussion, and conclusion

This repository is an index. Detailed experiment records remain in their individual repositories.
